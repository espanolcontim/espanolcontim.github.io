# Поиск и превью ссылок

## Что настроено

- **`/sitemap.xml`** — все страницы для поиска: главная, список уроков, уроки, открытые конспекты и допматериалы, упражнения. Генерируется при сборке из уроков (`apps/web/src/app/seo.ts`, `pages/sitemap.xml.ts`), адрес сайта — из `site` в `astro.config` (`SITE_URL`).
- **`/robots.txt`** — всё открыто, ссылка на sitemap.
- **`noindex`** — у страниц, которым нечего делать в поиске: заглушки закрытых частей («в подписке „Практика“»), повторение (личная страница), 404. Их нет в sitemap, у них нет canonical.
- **title и description** — свои у каждой страницы; описание урока — до 160 символов (столько Яндекс показывает в сниппете).
- **canonical** — адрес страницы на основном домене `https://espanolcontim.ru`.
- **Open Graph** — превью ссылки в Telegram, VK, WhatsApp: картинка `apps/web/src/assets/og.png` (одна на сайт, в стиле обложек), заголовок и описание страницы (`app/Seo.astro`).
- **Значки** — кремовая «T» (Tim) с тильдой, как у «ñ», на синем, цвета темы «Sorolla 2»; `apps/web/public/`: `favicon.ico` (16, 32, 48 — для вкладки), `favicon.png` (120×120, его Яндекс показывает в выдаче), `apple-touch-icon.png` (180×180, квадрат — iOS скругляет сам).
- **404** — своя страница со ссылками на уроки; бакет отдаёт её с кодом 404.
- **Яндекс Вебмастер** — мета-тег подтверждения на главной: `YANDEX_VERIFICATION` в `app/seo.ts`.

## Как проверить после деплоя

1. **Файлы.** Открыть https://espanolcontim.ru/robots.txt и https://espanolcontim.ru/sitemap.xml. В sitemap — полные адреса, без `/repaso/` и без закрытых допматериалов.
2. **Теги страницы.** Открыть страницу, Ctrl+U (исходный код), в `<head>`: `<title>`, `description`, `canonical`, `og:title`, `og:image`. Ссылку из `og:image` открыть — должна показаться картинка.
3. **Превью ссылки.**
   - Telegram: отправить ссылку себе в «Избранное». Telegram запоминает превью надолго; если поменяли картинку или заголовок — отправить ту же ссылку боту `@WebpageBot`, он обновит.
   - VK, WhatsApp: отправить ссылку себе. VK тоже кэширует превью, обновляет не сразу.
4. **Яндекс Вебмастер** (https://webmaster.yandex.ru):
   - «Добавить сайт» → `https://espanolcontim.ru` → способ подтверждения «Мета-тег» → «Проверить». Код `8ade9113bcce30a3` уже в `YANDEX_VERIFICATION` (вписан 28.10.2026). Для другого сайта — новый код вписать туда же (или прислать Claude) и задеплоить.
   - «Индексирование → Файлы Sitemap» → добавить `https://espanolcontim.ru/sitemap.xml`.
   - Старые адреса (`espanolcontim.github.io`, `espanolcontim.sourcecraft.site`) — сняты с публикации 28.10.2026; из Вебмастера их удалить.
   - «Инструменты»: «Анализ robots.txt», «Проверка ответа сервера» (страница — 200, несуществующая — 404), «Валидатор микроразметки» — покажет Open Graph страницы.
   - Через несколько дней: «Индексирование → Страницы в поиске» и «Диагностика».
5. **Lighthouse.** Chrome → F12 → Lighthouse → категория SEO → Analyze. Ожидаем 100 или около того.
6. По желанию — Google Search Console (тоже бесплатно), подтверждение тоже мета-тегом.

## Если что-то меняется

- **Новый домен.** `site` в `astro.config.mjs` (или `SITE_URL=…` при сборке) сам поменяет адреса в sitemap, robots.txt, canonical и `og:url`. Если сайт живёт на двух доменах, canonical на обоих должен вести на один основной.
- **Картинка превью** сделана разово: HTML-шаблон в стиле обложек (Manrope, цвета «Sorolla 2», фото) снят через Playwright. Сменилась тема или фото — перерисовать так же; новая картинка получит новый адрес, и превью обновятся.
- **Значки** от 32px нарисованы на canvas шрифтом Manrope (тильда и «T» отдельно, вместе — 68% высоты) и сняты через Playwright; 16px нарисован по пикселям — в нём шрифтовая тильда расплывается. Браузеры долго помнят старый значок: после замены — обновить страницу с Ctrl+Shift+R или открыть `/favicon.ico` напрямую.

## Яндекс Метрика

Метрика грузится только после «Принять» в уведомлении о cookie; до этого — ни скрипта, ни cookie. Номер счётчика — `METRIKA_ID` в `apps/web/src/app/analytics.ts` (113844829); `0` — на сайте нет ни Метрики, ни уведомления. Счётчик работает только на адресе, для которого собран сайт: локально его нет.

**Как подключить**
1. https://metrika.yandex.ru → «Добавить счётчик»: имя «Español con Tim», адрес `espanolcontim.ru`, часовой пояс Москва. Создан 28.10.2026: счётчик 113844829 (старый 113827960 был для `espanolcontim.github.io` — его можно удалить).
   - «Включая поддомены» — выключить: `www` переадресуется на адрес без www, других поддоменов нет.
   - «Принимать данные только с указанных адресов» — включить.
   - «Вебвизор, карта скроллинга, аналитика форм» — выключить: в коде он и так выключен (`webvisor: false`), а в политике сказано, что записи действий нет.
   - Отслеживание хеша — выключить: адреса наборов упражнений (`#p1`, `#quiz`) не отдельные страницы.
   - Код счётчика со страницы настроек вставлять не нужно: сайт подключает Метрику сам, после согласия.
2. Номер счётчика вписать в `METRIKA_ID` и задеплоить.
3. «Цели» → «Добавить цель» → «JavaScript-событие», по одной на идентификатор:
   - `boosty` — клик по ссылке на Boosty;
   - `practice_done` — пройден набор упражнений;
   - `quiz_done` — пройдена проверка после урока;
   - `review_start` — начато занятие повторения.
4. В Вебмастере: «Настройки → Привязка к Метрике» — Яндекс быстрее узнаёт о новых страницах.

**Как проверить**
- Открыть сайт в окне инкогнито: внизу уведомление о cookie. До «Принять» во вкладке «Сеть» (F12) нет запросов к `mc.yandex.ru`, после — есть.
- В Метрике: «Отчёты → Посещаемость» — визиты появляются через несколько минут; цели — «Отчёты → Конверсии».
- На странице политики (`/privacy/#cookie`) видно решение; «Отозвать согласие» — Метрика больше не грузится.
- Отладка: добавить к адресу `?_ym_debug=1` — в консоли браузера видно, что отправляет счётчик (только после «Принять»).
