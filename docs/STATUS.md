## Полезно знать

- Ветки (с 28.10.2026): разработка — в `develop`, push туда только проверяет; `main` — то, что на сайте, каждый push выкладывает. Выкладываем по слову Тимура (`CLAUDE.md`, «Как работаем»).
- Картинка превью ссылок (`assets/og.png`) сделана разово: HTML-шаблон в стиле обложек снят через Playwright. Значки (`public/`) — кремовая «T» с тильдой на синем: от 32px — шрифт Manrope, снято через Playwright; 16px нарисован по пикселям. Сменится тема или фото — перерисовать (см. `docs/seo.md`).
- Фото на главной вырезано из однотонного фона разовым скриптом (sharp, в репозиторий не клали). Новое фото — тоже на однотонном фоне, вырезать так же.
- Страница «Подписка» (в SPEC — «Разделы сайта»: что входит в «Практику», ссылка на Boosty, как войти) ни в одну фазу не вписана. Пока плашки ведут прямо на Boosty; страницу логично сделать в фазе 2 вместе со входом.
- `content/private` в git нет: на новом компьютере его создаёт `npm run content:import`.
- Скрипты из `scripts/` запускаются обычным `node` без сборки, поэтому все импорты — с расширением `.ts`.
- Astro 7 не запускается на Node ниже 22.23.4 (на компьютере Тимура через nvm стоит 22.22.3 — `npm run build` и `npm run dev` падают). Обновить: `nvm install 24`. В CI GitHub и SourceCraft — Node 24.
- TypeScript держим на 6.0: TS 7 пока не поддерживают `astro check` и языковой сервер Astro.
- У «Песка» терракота на плашках формул в конспекте (`--accent` на `--accent-soft`) — 4.31:1, чуть ниже 4.5. У «Sorolla 2» всё не ниже 4.5:1. Если вернуть «Песок» — задать в `themes/sand.css` светлее `--base-accent-soft`.
- `packages/content` помечен `"sideEffects": false`: остров тренажёра берёт из него проверку ответа, а zod в браузерный бандл не попадает (остров — 18 КБ без React).
- Композиционных корней два: `app/container.ts` — для сборки (в нём весь контент), `app/browser.ts` — для островов и скриптов в браузере (прогресс).
- Фразы для повторения встроены в страницу `/repaso/` (24 КБ в сжатом виде на 377 фраз). Когда уроков станет много, вынести их в отдельный JSON, который страница подгружает.
- Вёрстку проверяли через Playwright из `../video-lessons/node_modules`: по всем страницам — прокрутка вбок, контраст, размер шрифта и целей касания. Отдельного скрипта в проекте нет — добавить, если понадобится регулярно.
