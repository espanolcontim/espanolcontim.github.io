## Ответы для формы на pd.rkn.gov.ru

Паспорт, СНИЛС и адрес регистрации подставляются из Госуслуг и вписываются в форму — в репозиторий их не записываем. Сведения реестра операторов общедоступны (ч. 4 ст. 22 152-ФЗ), кроме средств обеспечения безопасности.

**Сведения об операторе.** Тип — физическое лицо. Адрес — адрес регистрации, почтовый — «совпадает». Телефон, факс — можно не заполнять. Почта — ящик на Яндексе. Регионы обработки — все субъекты РФ.

**Цели.** В каждой — «иная» и свой текст; способ обработки везде — автоматизированная, с передачей по сети Интернет.

1. *Сбор статистики посещений сайта «Español con Tim» с помощью сервиса Яндекс Метрика для улучшения сайта и учебного курса.*
   Категории — «сведения, собираемые посредством метрических программ». Субъекты — «Посетители сайта». Основание — согласие. Действия — всё, кроме «распространения» и «иных действий».
2. *Обеспечение работы и безопасности сайта «Español con Tim».*
   Категории — «иные персональные данные» (IP-адрес и сведения о браузере в журналах хостинга). Субъекты — «Посетители сайта». Основание — «необходима для осуществления прав и законных интересов оператора…». Действия — сбор, запись, хранение, использование, удаление, уничтожение.
3. *Ответы на обращения, направленные оператору по электронной почте.*
   Категории — «фамилия, имя, отчество», «адрес электронной почты». Субъекты — «Посетители сайта», «Клиенты». Основание — согласие. Действия — сбор, запись, систематизация, накопление, хранение, использование, удаление, уничтожение.
4. *Предоставление подписчикам Boosty доступа к материалам сайта «Español con Tim», вход на сайт по ссылке из письма, хранение учебного прогресса подписчиков.*

Субъекты — «Клиенты». Основания — согласие и «исполнение договора, стороной которого является субъект». Действия — всё, кроме «распространения» и «иных действий».
