# Español con Tim — спецификация сайта

## Зачем сайт

Сейчас конспекты к урокам выходят в PDF в Telegram и на Boosty. Сайт должен дать то, чего нет в PDF:

- удобная навигация по урокам и конспектам;
- тренажёр с автопроверкой, ради которого возвращаются каждый день (это и удерживает подписку);
- интервальное повторение;
- проверки после уроков.

Telegram в России работает с перебоями, поэтому сайт со временем может стать основным местом для материалов.

## Аудитория и метод

- Русскоязычные, начинают с нуля, иногда знают немного английского. Большинство заходит с телефона.
- Курс построен по методу Мишеля Томаса: перевод предложений с русского на испанский, новые слова появляются только внутри предложений.
- Уровни: подготовительный A0 (базовая грамматика простым языком), затем A1 и выше. Видео выходят примерно два раза в неделю.

## Видео

Видео на сайт не встраиваются. В шапке и на главной — ссылка на YouTube-канал «Español con Tim»: https://www.youtube.com/@espanolcontimur. На странице урока — кнопка «Смотреть урок на YouTube», ведущая на видео этого урока. Ссылок на видео в `video-lessons` нет: их ведёт Тимур в `content/videos.json`. Если ссылки на видео урока нет, кнопка ведёт на канал.

## Модель доступа

Boosty: уровни «Практика» (290 ₽/мес) и «Поддержка курса» (490 ₽/мес) открывают одинаковый доступ.

| Часть урока | A0 | A1 и выше | Первый урок любого уровня |
|---|---|---|---|
| Краткий конспект (выжимка) | бесплатно | бесплатно | бесплатно |
| Конспект (полный) | бесплатно | по подписке | бесплатно |
| Упражнения по фразам урока | бесплатно | по подписке | бесплатно |
| Дополнительные материалы: тексты и упражнения к ним | по подписке | по подписке | бесплатно |
| Проверка после урока | бесплатно | бесплатно | бесплатно |
| Итоговый тест уровня | по подписке | по подписке | — |

- Упражнения по фразам урока открыты так же, как конспект: это те же фразы, что в разделе «Практика» полного PDF-конспекта.
- Вся таблица задаётся в `packages/content/src/access.ts`. Модель может поменяться — это должно делаться правкой одного конфига.
- Повторение (Repaso) строится только из предложений, к которым у пользователя есть доступ.
- Предложения, которые используются только в платных частях, при импорте уходят в `content/private`.

Подписчики входят на сайт по ссылке, которая приходит на почту, указанную в их аккаунте Boosty. Входить нужно один раз на каждом устройстве.

## Оформление

- Стиль — как у обложек канала: минимализм, типографика, воздух. Дизайн лёгкий и плотный: шрифт 15px, тонкие линии вместо заливок, скругления минимальные (решение Тимура). Образцы обложек лежат в `docs/design/` (если папки нет — попросить у Тимура 2–3 картинки).
- **Палитра должна меняться легко.** Все цвета — только через CSS-переменные (токены) в одном файле темы. Палитра задаётся несколькими базовыми цветами (фон, текст, акцент, состояния «верно / почти / ошибка»), остальные оттенки выводятся из них. Тёмная тема — тот же набор токенов с другими значениями. По умолчанию тема светлая, системная настройка её не переключает; тёмная — атрибутом `data-theme="dark"` на `<html>`. На сайте тёмной темы пока нет (решение Тимура): палитры для неё готовы, переключателя нет. В компонентах нет ни одного захардкоженного цвета.
- Предложить 2–3 варианта палитры, Тимур выбирает. Переключение между вариантами — заменой значений токенов, без правки компонентов.
  - Выбрана «Sorolla 2» — палитра слайдов из `video-lessons` (решение Тимура). Вторая тема — «Песок» (по обложкам).
  - Каждая тема — свой файл в `apps/web/src/shared/styles/themes/`; активная — одна строка `@import` в `theme.css`. Тема задаёт базовые цвета для светлой и тёмной, по желанию — любой производный; остальное выводится.

## Разделы сайта

- **Главная.** О курсе и методе, как заниматься, кнопка «Начать с урока 1», ссылки на YouTube, Boosty и Telegram.
- **Уроки (Lecciones).**
  - Слева на всех страницах — меню всех уроков по уровням: A0 и уровень открытого урока раскрыты, остальные свёрнуты; открытый урок подсвечен. На широком экране меню видно всегда, на телефоне — по кнопке «Уроки».
  - Список по уровням с отметками прогресса; платные уроки видны с пометкой подписки.
  - Слайдов и текста за кадром на сайте нет: JSON урока из `video-lessons` — только источник данных.
  - Страница урока `/lessons/a0-11/`: «Урок 11», уровень и «11/14», тема, грамматика урока, кнопка «Смотреть урок на YouTube», выжимка, переходы в подразделы и к соседним урокам.
  - Подразделы урока:
    - **Конспект** `/lessons/a0-11/notes/` — как полный PDF, только оформленный лучше: оглавление, теория по разделам (слова с транскрипцией, правила-формулы, спряжения, «так говорят / так не говорят»), сводные таблицы, диалоги, новые слова, итог урока.
    - **Дополнительные материалы** `/lessons/a0-11/extras/` — текстом: живые выражения, мини-история с вопросами, фразы с характером, «Испания изнутри», «Ваш ход» с образцом.
    - **Упражнения** `/lessons/a0-11/practice/` — отработка, см. ниже; в конце — проверка после урока.
- **Упражнения (Práctica).**
  - Фразы урока: перевод RU→ES (основной тип), порядок слов.
  - Из допматериалов: перевод RU→ES, «найдите ошибку», «вставьте слово» (выбор из вариантов), перевод ES→RU с самопроверкой.
  - Панель символов, мгновенная проверка, эталон и пояснение при ошибке, итог сессии.
- **Повторение (Repaso).** `/repaso/`. Ежедневное повторение предложений из пройденных уроков, счётчик «на сегодня» в шапке.
- **Проверка (Examen).** Проверка после урока (8–10 заданий, результат, разбор ошибок) — в конце подраздела «Упражнения». Итоговый тест уровня — из фраз всех уроков уровня.
- **Подписка.** Что входит в «Практику», ссылка на Boosty, как войти на сайт.
- **Вход.** Поле для почты, экран «проверь почту», страница-обработчик ссылки из письма.
- **Прогресс.** Хранится в localStorage. Экспорт и импорт в JSON для переноса между устройствами.

### Фаза 2 — вход для подписчиков Boosty

Ресурсы в облаке, что где и как развернуть — `docs/backend.md`.

Схема: статика в Object Storage (`espanolcontim.ru`) → Yandex API Gateway на `api.espanolcontim.ru` → функция `api`. Функция `sync` работает по таймеру. Данные лежат в приватном бакете Object Storage, письма уходят через SMTP Яндекс Почты. Всё в бесплатных лимитах, но нужен платёжный аккаунт Yandex Cloud с картой.

**Функция `sync`** (раз в час) — `functions/sync/`, общий с `api` код — `functions/shared/`; как устроена и что лежит в бакете — README, «Функция sync». Код и тесты готовы, проверено 30.10.2026 на настоящем Boosty с папкой `.bucket` вместо бакета (`npm run sync:local`); в облаке ещё не развёрнута.
- [x] Получает подписчиков через неофициальный API Boosty (`functions/sync/src/boosty.ts`):
  - `GET https://api.boosty.to/v1/blog/espanolcontim/subscribers?sort_by=on_time&offset=N&limit=100&order=gt`;
  - заголовок `Authorization: Bearer <accessToken>`;
  - `offset` — сколько записей уже выдано; в ответе — `offset` следующей страницы, в конце — пустая страница (проверено с `limit=1`).
- [x] Платные — это `level.price > 0`; активные — `subscribed === true` и `status === "active"`. Пустой email приходит как `""` (аккаунты, созданные через VK). На 30.10.2026 платных подписчиков нет: 2 записи, обе — бесплатный уровень.
- [x] Обновляет токен Boosty через refresh token: `POST https://api.boosty.to/oauth/token/`, форма `grant_type=refresh_token`, `refresh_token`, `device_id` (ключ `_clentId` из Local Storage boosty.to), `device_os=web` — как в boostylib. В ответе `access_token`, `refresh_token`, `expires_in` (2592000 — 30 дней); refresh token каждый раз новый, поэтому новая пара сразу пишется в бакет. Обновляет за неделю до конца и при 401. Токены — `boosty/auth.json` в приватном бакете.

**Функция `api`**
- [ ] `POST /auth/request {email}`:
  - если почта есть среди активных платных — письмо со ссылкой для входа (подписанный токен на 15 минут, передаётся в hash URL);
  - ответ всегда одинаковый, чтобы не раскрывать, есть ли такой подписчик;
  - ограничение частоты запросов; рассмотреть Yandex SmartCaptcha (бесплатна до 10 тыс. запросов в месяц — по тарифам на 27.10.2026).
- [ ] `POST /auth/verify {token}` → сессия JWT на 90 дней. Субъект сессии — **Boosty id, а не email**.
- [ ] `POST /auth/refresh` → скользящее продление, если токену больше 7 дней.
- [ ] `GET /lessons/:id/body` → проверка сессии и активной подписки по Boosty id (по кэшу) → платный JSON из бакета.
- [ ] Сессия хранится в localStorage и передаётся в заголовке `Authorization`. Куки не подходят: сайт и API на разных доменах. CORS — только для адреса сайта: `https://espanolcontim.ru`.

## Схема контента

Согласована с Тимуром 26.10.2026. Что лежит в `../video-lessons` и в каком формате — `docs/content-sources.md`.

```ts
// packages/content/src/schema.ts — набросок
const Level  = z.enum(['A0', 'A1', 'A2', 'B1', 'B2'])                 // как в video-lessons
const Part   = z.enum(['summary', 'notes', 'practice', 'extras', 'quiz'])
const Access = z.enum(['free', 'paid'])

const LessonId   = z.string().regex(/^(a0|a1|a2|b1|b2)-\d{2}$/)          // a0-11: уровень + planLesson
const SentenceId = z.string().regex(/^(a0|a1|a2|b1|b2)-\d{2}-s\d{2,3}$/) // a0-11-s07
const ExerciseId = z.string() // a0-11-s07.order — упражнение на предложении; a0-11-x05 — остальное из допматериалов

/** Строка с выделением нового: "Quiero **aprender** español." Звёздочки парные. */
const Marked = z.string().min(1).refine(hasEvenMarks)
const Phrase = z.object({ es: Marked, ru: Marked, ipa: z.string().optional() })

// --- content/public/index.json: метаданные всех уроков
const LessonMeta = z.object({
  id: LessonId,                   // он же адрес /lessons/a0-11/
  number: z.number().int(),       // «Урок 11» — сквозной номер, как в видео
  level: Level,
  planLesson: z.number().int(),   // «11/14», как на обложке
  title: z.string(),
  grammar: z.array(z.string()),   // newGrammar
  youtubeUrl: z.url().optional(), // из content/videos.json
  parts: z.object({ summary: Access, notes: Access, practice: Access, extras: Access, quiz: Access }).partial(),
})                                // parts считает access.ts; нет ключа — нет части

// --- предложение: единица тренажёра и повторения
const Sentence = z.object({
  id: SentenceId,
  ru: Marked,                         // задание
  hint: z.string().optional(),        // «вежливо», «в 11 утра» — часть задания
  es: z.array(Marked).min(1).max(3),  // эталон + alternatives
  ipa: z.string().optional(),
  why: z.string().optional(),         // пояснение при ошибке (есть у «найдите ошибку»)
})

const Exercise = z.discriminatedUnion('type', [
  z.object({ id: ExerciseId, type: z.literal('translate'), sentenceId: SentenceId }),  // RU→ES
  z.object({ id: ExerciseId, type: z.literal('order'), sentenceId: SentenceId }),      // плашки — из эталона
  z.object({ id: ExerciseId, type: z.literal('fix'), wrong: z.string(), sentenceId: SentenceId }),
  z.object({ id: ExerciseId, type: z.literal('gap'), text: Marked, answer: z.string(), // text с одним ___
             options: z.array(z.string()).min(2), ru: z.string().optional() }),
  z.object({ id: ExerciseId, type: z.literal('read'), es: Marked, ru: z.string() }),   // ES→RU, самопроверка
])

// --- части урока
const Summary = z.object({            // выжимка
  phrases: z.array(Phrase).min(6).max(10),
  rule: Marked,
  mistake: z.object({ wrong: Side, right: Side }),   // Side = { label?, es, ru? }
  practice: z.array(SentenceId).min(3).max(5),
})

const Notes = z.object({              // конспект, как полный PDF
  sections: z.array(z.object({
    id: z.string(), title: z.string(), hint: z.string().optional(),
    blocks: z.array(z.discriminatedUnion('type', [Words, Rule, Conjugation, ConjugationCompare, Compare])),
  })),
  tables: z.array(Grid),              // handoutTables
  dialogues: z.array(Dialogue),
  vocabulary: z.array(VocabEntry),    // newVocabulary + ipa, найденная во фразах, как в lesson-pdf.ts
  outcome: z.object({ title: z.string(), bullets: z.array(z.string()),
                     next: z.object({ title: z.string(), text: z.string() }) }).optional(),
})

const Practice = z.array(z.object({   // фразы урока по группам → упражнения
  group: z.string(), sentenceIds: z.array(SentenceId),
}))

const Extras = z.object({             // extras/lesson-NN.json
  expressions: z.array(Expression),
  exercises: z.array(z.object({ title: z.string(), items: z.array(Exercise) })), // → подраздел «Упражнения»
  story: Story, phrases: z.array(Phrase), culture: Culture, yourTurn: YourTurn,
})

// --- тело урока: одна форма для content/public и content/private, сайт склеивает
const LessonBody = z.object({
  id: LessonId,
  summary: Summary.optional(),
  notes: Notes.optional(),
  practice: Practice.optional(),
  extras: Extras.optional(),
  quiz: z.array(Exercise).optional(),
  sentences: z.array(Sentence),       // только те, на которые ссылаются части этого файла
})

const LevelTest = z.object({ level: Level, exercises: z.array(Exercise), sentences: z.array(Sentence) })
```

- **Доступ** (`access.ts`): `summary` и `quiz` — всегда бесплатно; `notes` и `practice` — бесплатно для A0 и первого урока уровня; `extras` — бесплатно для первого урока уровня; итоговый тест — по подписке.
- **Файлы.** `content/public/index.json` — метаданные уроков; `content/public/lessons/<id>.json` — бесплатные части урока; `content/private/lessons/<id>.json` — платные; `content/ids.lock.json` — постоянные id; `content/videos.json` — ссылки на видео.
- **Раскладка.** Импорт пишет бесплатные части урока в `content/public`, платные — в `content/private`. Предложение попадает в public, если на него ссылается хотя бы одна бесплатная часть, иначе — в private.
- **Стабильные id.** `video-lessons` не меняем, поэтому id выдаёт импорт и хранит в `content/ids.lock.json` (коммитится; в нём только хэши фраз, без текста). Ключ предложения — хэш нормализованных `ru` + `hint` + `es`: без регистра, `**`, пунктуации, `¿¡` и диакритики. Новое предложение получает следующий номер в уроке, номера исчезнувших не переиспользуются. Отредактированная фраза получает новый id: импорт показывает «исчезли / появились», и старый номер можно вернуть правкой lock-файла.
- **Варианты ответа** — только из данных: `es` + `alternatives`. Регистр, пробелы, пунктуация и `¿¡` нормализуются; ответ без диакритики — «почти верно». В «Найдите ошибку», где ошибка — в знаке над буквой или в `¿¡`, исправить нужно именно её: без этого ответ неверный, а не «почти».
- **Проверка после урока** собирается при импорте: 10 заданий из последней группы практики урока (при нехватке — из предыдущих); две фразы из 3–8 слов — «собери фразу», остальные — перевод. Если понадобятся ручные проверки — файлы `content/quizzes/<id>.json` в этом репозитории.
- **Ссылки на видео** — `content/videos.json`: `{ "channel": "https://www.youtube.com/@espanolcontimur", "lessons": { "a0-01": "https://www.youtube.com/watch?v=…" } }`.
