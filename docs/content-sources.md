# Источники контента: `../video-lessons`

Изучено 26.10.2026, состояние на коммите `23bba4a` («handouts: lesson 11»).
`video-lessons` — только чтение, его формат тоже не меняем: всё, чего сайту
не хватает, делается на стороне сайта (см. конец файла).

## Коротко

- Источник правды — два вида JSON: `lessons/lesson-NN.json` (урок как набор
  слайдов для записи видео + выжимка + сводные таблицы) и
  `extras/lesson-NN.json` (платные допматериалы). PDF, PNG и словарь
  генерируются из них.
- Сейчас 11 уроков, все A0 (уроки 1–11 из 14). У всех есть `summary` и
  `extras`, `handoutTables` — только у урока 8.
- Валидатор есть, но рукописный (без zod): `src/features/lessons/parse.ts`
  для уроков, `scripts/extras.ts` для допматериалов, общий запуск —
  `npm run lessons:validate`.
- Нет: ссылок на YouTube, стабильных id предложений, проверок после урока,
  итоговых тестов уровня.

## Нумерация

- `number` — сквозной номер в курсе, 1–84, он же в имени файла.
  `LEVEL_RANGES` (`scripts/lessons.ts`): A0 — 1–14, A1 — 15–39, A2 — 40–64,
  B1 — 65–84.
- `level` — `A0` | `A1` | `A2` | `B1` | `B2` (B2 в типах есть, в плане нет).
- `planLesson` — номер внутри уровня; пара `level + planLesson` уникальна.
- Отдельного id урока в JSON нет; приложение слайдов использует `String(number)`.
- На обложке «11/14» = `planLesson` / уроков в уровне. Видео называется
  «Урок 11» — по `number`.
- Для сайта id урока = `a0-11` (уровень + `planLesson` с ведущим нулём).
  «Первый урок уровня» = `planLesson === 1`.

## Урок: `lessons/lesson-NN.json` (`schemaVersion: 3`)

Верхний уровень:

| Поле | Что это |
|---|---|
| `schemaVersion` | всегда `3` |
| `number`, `level`, `planLesson` | см. «Нумерация» |
| `title` | тема урока: «Вопросы» |
| `course` | «Испанский с нуля» |
| `newVocabulary` | новые слова `{ es, ru, pos, ipa? }`, на слайды не выводятся |
| `newGrammar` | новые конструкции, массив строк |
| `speakers` | ключ → имя (`ana` → `Ana`) |
| `tableHeaders` | подписи колонок таблиц `{ es, ru }` |
| `practiceGroups` | группы практики `{ name, pauseMs? }`, 3–4 на урок, последняя обычно «Всё вместе» |
| `slides` | слайды по порядку |
| `summary` | выжимка (необязательна, есть у всех 11) |
| `handoutTables` | сводные таблицы только для полного конспекта (есть у урока 8) |

Слайды (общие поля `type`, `id?`, `notes?`):

| `type` | Поля | Лимит | На сайте |
|---|---|---|---|
| `title` | `agenda?` | — | нет |
| `section` | `title`, `hint?` | — | заголовок раздела конспекта |
| `table` | `title`, `headers?`, `rows: {es, ru, ipa}[]` | ≤ 5 строк, `ipa` обязательна; длинные режутся на слайды с одинаковым `title` | таблица слов, части склеиваются |
| `rule` | `title`, `pattern: string[]`, `text?`, `examples: Phrase[]` | ≤ 3 примеров | правило: формула + примеры |
| `conjugation` | `verb`, `ru`, `rows: {pronoun, stem, ending, ru, ipa?}[]` | ≤ 6 строк | спряжение, окончание выделено |
| `conjugationCompare` | `title`, `verbs: [{verb, ru}, {verb, ru}]`, `rows: {pronoun, forms: {stem, ending, ipa?}[]}[]` | ровно 2 глагола, ≤ 6 строк | два спряжения рядом |
| `compare` | `title`, `left`/`right: {label, tone?: wrong\|right, items: {es, ru?, ipa?}[]}` | ≤ 3 пунктов | сравнение, «так не говорят / так говорят» |
| `practice` | `group`, `phrase: {ru, es, ipa?, hint?, alternatives?}`, `pauseMs?` | `alternatives` ≤ 2 | **предложение для тренажёра и повторения** |
| `dialogue` | `title`, `lines: {speaker, es, ru}[]` | ≤ 4 реплик, длинные режутся | диалог, части склеиваются |
| `final` | `title`, `bullets`, `nextTitle`, `nextText`, `outro?` | — | «Теперь вы умеете» + анонс |

- **Фраза** везде одной формы: `{ es, ru, ipa? }`.
- **Выделение нового** — `**…**` прямо в строке, в `es`, `ru` и `alternatives`.
  Звёздочки парные. В `hint`, `text`, `label`, `pattern`, заголовках не работает.
- **IPA** обязательна в `table` всегда и во всех фразах уроков A0. Запись
  кастильская широкая, `β ð ɣ ʎ` запрещены. Manrope знаков МФА не содержит —
  в слайдах транскрипция набрана отдельным шрифтом (`--font-ipa`).
- **`notes`** — текст автора за кадром (с пометками `🎥 КАМЕРА`, `🔊`, `⏱`).
  В PDF-конспект не попадает.
- Неизвестные поля приложение слайдов **молча игнорирует** — можно добавлять
  поля для сайта, не ломая слайды (но `parse.ts` их тогда не проверит).

- Одна и та же русская фраза бывает с разными ответами, различает их только

## Краткий конспект (выжимка): `summary`

Раздел 13 справочника. Структура, а не текст:

| Поле | Что это | Лимит |
|---|---|---|
| `phrases` | ключевые фразы `{ es, ru, ipa? }` | 6–10 |
| `rule` | главное правило, 2–3 строки, `**…**` выделяет | — |
| `mistake` | `{ wrong, right }`, каждая сторона `{ es, ru?, label? }` | одна |

- `summary.phrases` — в основном строки таблиц (у урока 6 — только 3 из 8).

## Полный конспект

Отдельного источника нет: `scripts/lesson-pdf.ts` собирает его из слайдов.
Порядок:

1. Шапка: курс, «Урок N. Тема», «Уровень A0, урок 11 · Грамматика: …» (`newGrammar`).
2. Теория по разделам `section` (с `hint`): `table`, `rule`, `conjugation`,
   `conjugationCompare`, `compare`. Подряд идущие `table` с одинаковым
   `title` склеиваются. Разделы без теории («Практика», «Мини-диалог») пропускаются.
3. Сводные таблицы `handoutTables`.
4. Практика по группам: русская фраза + `hint`, пустая колонка для ответа.
5. Диалоги (подряд идущие с одинаковым `title` — один диалог).
6. Новые слова `newVocabulary` с транскрипцией: своя `ipa` или найденная
   во фразах этого и других уроков.
7. Итог: `final.title`, `bullets`, `nextTitle: nextText`.
8. С новой страницы — ответы к практике (`es` + «или …» `alternatives`).

`notes` (текст за кадром) и `title`-слайд в конспект не входят.

## Проверки в `video-lessons`

| Команда | Что делает |
|---|---|
| `npm run lessons:validate` | все уроки через `parse.ts` + `derive.ts`; номера в диапазоне уровня; `planLesson`; допматериалы через `extras.ts`. Только читает |
| `npm run vocab:check -- NN` | слова, не введённые раньше (в уроке и в допматериалах) |
| `npm run check:slides` | вёрстка слайдов в браузере (нужен `npm run dev`) |

Импорт сайта не должен импортировать TS из `video-lessons` (другой проект,
React, свой tsconfig). Он читает JSON и проверяет его своей zod-схемой
источника, повторяющей правила `parse.ts` и `extras.ts`.

## Чего не хватает сайту и как закрываем

Решение Тимура: `video-lessons` не трогаем, даже формат. Всё закрывается
на стороне сайта (подробно — «Схема контента» в `docs/SPEC.md`).

| Чего нет | Как закрываем |
|---|---|
| **Стабильные id.** Явных `id` нет ни у одного слайда; `derive.ts` строит `practice-7` по порядку, вставка фразы сдвигает номера. У заданий допматериалов id нет | импорт выдаёт id и хранит их в `content/ids.lock.json`: ключ — хэш нормализованных `ru` + `hint` + `es`. Правка фразы = новый id, старый можно привязать вручную |
| **Допустимые варианты для ввода.** `alternatives` ≤ 2, у многих заданий их нет (урок 1: 2 из 26) | только `es` + `alternatives` + нормализация в функции проверки |
| **Пояснение при ошибке.** У практики урока нет; у `fix` в допматериалах есть `why` | показываем эталон и варианты; `why` — где есть |
| **Ссылки на видео** | `content/videos.json` ведёт Тимур; канал — https://www.youtube.com/@espanolcontimur |
| **Проверка после урока** | собирается при импорте из последней группы практики урока |
| **Итоговый тест уровня** | собирается из фраз всех уроков уровня |
| **Разметка языка внутри русского текста** (`summary.rule`, `hint`, `final.bullets`) — испанские слова не отмечены | `lang="es"` ставим только на целые испанские поля |

На сайт не попадают: слайды как таковые, `title`-слайд, текст за кадром
(`notes`), паузы практики (`pauseMs`).
