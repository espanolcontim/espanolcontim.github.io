# Хостинг в Yandex Object Storage со своим доменом

Решение Тимура (27.10.2026): основной хостинг — Object Storage на своём домене `espanolcontim.ru`, DNS — в Yandex Cloud DNS. Домен и DNS — платные (~920 ₽ в год), это согласованное исключение из правила «ноль рублей». Где остановились — «Ход переезда» ниже.

Зачем: SourceCraft Sites не даёт свою страницу 404, не сжимает файлы, не отдаёт заголовков кэширования, ставит cookie `_yasc` и не поддерживает свой домен (`docs/sourcecraft.md`, «Как отдаёт сайт»). Object Storage — тоже ООО «Яндекс.Облако» и тоже Россия: в политике и в уведомлении в Роскомнадзор меняется только адрес сайта.

Что даёт:
- своя `404.html` («Страница ошибки» в настройках бакета);
- `Cache-Control` для каждого файла: `/_astro/*` — на год (имена с хэшем), HTML — с проверкой; `ETag` и `Last-Modified` — сами (ответ 304);
- сжатие: файлы загружаем уже сжатыми (gzip) с заголовком `Content-Encoding` — проверить на живом бакете;
- свой домен с HTTPS (Let's Encrypt через Certificate Manager);
- деплой из GitHub Actions сразу после push, без двухчасовой синхронизации зеркала.

## Деплой

При каждом push в `main` `.github/workflows/deploy.yml` проверяет и собирает сайт (адрес по умолчанию — `https://espanolcontim.ru`) и запускает `scripts/deploy-bucket.ts` (правила — `scripts/deploy/bucket.ts`, с тестами). Скрипт работает через AWS CLI, который есть на раннерах GitHub; ключ `site-deploy` передаётся только в этот шаг.

- Текст (HTML, JS, CSS, SVG, XML, TXT, JSON) лежит в бакете сжатым gzip, с `Content-Encoding: gzip`. Картинки и шрифты не сжимаются. `Content-Type` берётся из таблицы `TYPES`: файл незнакомого типа останавливает деплой — допишите тип в таблицу.
- `/_astro/*` — `Cache-Control: public, max-age=31536000, immutable`, остальное — `no-cache`.
- Загружаются только изменённые файлы: MD5 сравнивается с ETag в бакете. Обычно деплой — это HTML и новые файлы в `_astro/`. Сначала грузится `_astro/`, потом прочее, HTML — последним; удалённые из сборки файлы удаляются в самом конце.
- Поменялись только заголовки (по ETag этого не видно) — Actions → «Деплой» → «Run workflow» с галочкой «Загрузить в бакет все файлы заново».
- Скрипт не запустится, если в сборке нет `index.html`, `404.html` или `sitemap.xml`, а также если сборка сделана не для `https://espanolcontim.ru`: пустая или чужая сборка стёрла бы сайт.

### Как отдаёт сайт

Проверено 28.10.2026 на `https://espanolcontim.ru`:

- страницы, sitemap, robots.txt и значки — 200 с правильным `Content-Type`; текст — `Content-Encoding: gzip` (главная — 3,6 КБ вместо 13);
- `/_astro/*` — `Cache-Control: public, max-age=31536000, immutable`, остальное — `no-cache`; есть `ETag` и `Last-Modified`, повторный запрос с `If-None-Match` — 304;
- нет страницы — своя `404.html` с кодом 404;
- `/lessons/a0-01` → 302 на `/lessons/a0-01/` (так отвечает сам бакет, не 301; поисковикам хватает canonical);
- `http://` → 301 на `https://`; `https://www.` → 301 на `https://espanolcontim.ru` с тем же путём; `http://www.` — в два шага, через `https://www.`;
- cookie хостинг не ставит (у SourceCraft была `_yasc`);
- gzip отдаётся и без `Accept-Encoding` — его понимают все браузеры и поисковые роботы;
- canonical, sitemap (36 адресов), robots.txt и картинка превью — на `https://espanolcontim.ru`.

1. **Домен.** Купить `espanolcontim.ru` в Timeweb или Beget — только домен, без хостинга и без платных услуг (DNS будет в Яндекс Облаке). Аккаунт — на `espanolcontim@yandex.ru`, с двухфакторной аутентификацией, автопродление включить. Для `.ru` спросят паспортные данные (так требуют правила зоны) — в публичном WHOIS их не видно, там «Private Person».

3. **Бюджет.** Billing → «Бюджеты» → создать: тип «Стоимость потребления», 100 ₽ в месяц, уведомления на 50 % и 100 %, получатель — вы.
4. **Бакет сайта.** Object Storage в каталоге `site` → «Создать бакет»:
   - имя — ровно как домен: `espanolcontim.ru`;
   - максимальный размер — 1 ГБ (чтобы случайно не платить за хранение);
   - «Чтение объектов» и «Чтение списка объектов» — «Для всех», «Чтение настроек» — ограниченное; класс хранилища — стандартное; шифрование не включать.
   - Вкладка «Веб-сайт» → «Хостинг»: главная страница `index.html`, страница ошибки `404.html`.
5. **Бакет для www.** Второй бакет `www.espanolcontim.ru` (так же 1 ГБ, «Для всех»), «Веб-сайт» → «Переадресация»: хост `espanolcontim.ru`, протокол HTTPS.
6. **DNS.** В бакете `espanolcontim.ru` → «Веб-сайт» → «Домены в Cloud DNS» → «Создать запись» → «Создать зону» `espanolcontim.ru.`. У регистратора указать DNS-серверы `ns1.yandexcloud.net` и `ns2.yandexcloud.net`. Обновление занимает до суток.
7. **Сертификат** (Cloud Console, каталог `site`; Certificate Manager — https://console.yandex.cloud/link/certificate-manager).
   1. «Добавить сертификат» → «Сертификат от Let's Encrypt»: имя `espanolcontim-ru`, домены `espanolcontim.ru` и `www.espanolcontim.ru` (без `*`), проверка — `DNS` → «Создать». *(Сделано.)*
   2. Сертификат → «Проверка прав на домены»: для каждого домена — запись **CNAME** (не TXT: TXT пришлось бы проходить заново каждые 60 дней). Кнопка «Создать запись» у нас записи не создала, поэтому — вручную: Cloud DNS → зона `espanolcontim.ru.` → «Создать запись»: имя `_acme-challenge` и `_acme-challenge.www`, тип CNAME, TTL 600, значение — из сертификата (`fpqmic94joo3lbr3q7mh.cm.yandexcloud.net.`). *(Сделано.)* Записи не удалять — по ним сертификат сам продлевается.
